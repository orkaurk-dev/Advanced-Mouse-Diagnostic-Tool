# Advanced Mouse Diagnostic Tool

A browser-based mouse testing tool that helps identify potential mouse issues by monitoring movement, clicks, scrolling, and drag-and-drop interactions. It records diagnostic events with timestamps, detects rapid successive clicks, tracks movement distance, and exports test results as JSON for further analysis and troubleshooting.

Designed to help users investigate problems such as inconsistent clicks, possible double-click issues, and unreliable mouse interactions, without installing additional software.

**Features:** Mouse movement tracking, left/right/middle click testing, rapid click detection, drag-and-drop testing, scroll monitoring, event logging, and JSON diagnostic exports.

*Note: The tool can help identify suspicious behaviour but cannot independently confirm hardware faults.*
